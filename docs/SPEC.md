# DMS Sweep — Rev 1 build spec

Static site, vanilla HTML/CSS/JS ES modules, no build step, no dependencies.
Served with `python3 -m http.server 8080` from the repo root. Desktop browsers only
(Chrome, Safari, Firefox on macOS/Windows). Rev 1 has no explanatory prose beyond the
labels and the first-run warning.

Plan, history and handoff live in `MASTER.md` at the repo root.

Design reference: the chosen mock is generated by `design/build_mocks.py` →
`design/Fastgraph.dc.html` and `design/WarnFastgraph.dc.html`. Its tokens and CSS
live in the `FG`, `F_CSS`, `f_band()`, `build_f()` and `build_f_warn()` section of
that script ("ROUND 3 — F · Fastgraph") and are the source of truth for colors,
geometry and type; the light theme comes from `LIGHT_TOKENS` in DMS Fastgraph's
`dms/ui/style_tokens.py`. Port it faithfully. The only gradients and shadows on the
page are the button recipe.

## Page structure (`index.html`)

The layout follows the Fastgraph artboard (`design/Fastgraph.dc.html`, built by
`build_f()` in `design/build_mocks.py`): toolbar, control row, sweep viewport,
response viewport, the bands / parametric-EQ grid, then the status bar — and the
first-run gate level starts at −20 dB. Max width 1440 centered, padding 14px 16px,
min width 1100; below that the page may scroll horizontally, do not build a phone
layout. The list below describes the earlier (rev 1) skeleton and is kept for the
element inventory; ids are unchanged.

1. **Top bar**: logo (yellow mark inside a 34 px black circle with a 1 px `--hair2` ring) +
   "DMS" bold, "Sweep" regular muted. Right: status dots "Tone" (yellow dot when playing),
   "EQ on" (yellow dot when eqOn; clicking toggles EQ), "Saved" (muted, briefly "Saved" after
   autosave), theme button (moon icon in light, sun in dark), and nothing else.
2. **Hairline rule.**
3. **Sweep strip**: left = caption "Drag slowly to sweep" + key hints; the tape (SVG, full
   width of the column, ~92 px tall). Right = big frequency readout (64 px Arial, tabular
   numerals, thin-space thousands: "3 100", small "Hz"), below it Level slider
   (−60…−6 dB, default −18) and a Stop/Play text button.
4. **Row**: left = "Response" caption + range caption, the graph (SVG, fills the column,
   ≥ 380 px tall). Right column (340 px): Mark panel then Bands list.
   - Mark panel: three pill buttons Start (1), Top (2), End (3). The next expected mark
     has the ink border; a mark already taken shows its frequency inside the pill
     (e.g. "Start 2.5k") and a filled state. Below: a Peak/Dip switch (key D toggles) and
     "Z undoes · Esc clears".
   - Bands: caption "Bands · n of 8". Rows: number (yellow when it is the band most
     recently created or selected), type select (PK / LSC / HSC shown as "Peak",
     "Low shelf", "High shelf"), fc field (Hz), gain field (dB, step 0.5), Q field
     (step 0.1), enable toggle, delete ×. Fields are plain inputs styled as text, no
     spinner; arrow keys step them. A 9th band is refused with the caption turning
     to "8 of 8 · remove one to add".
5. **Export row**: left = `<pre>` with the generic PEQ text. Right = "Preamp −2.0 dB"
   (editable field, plus a tiny "auto" link when manually overridden), "Session ↓ / ↑"
   (download JSON / load JSON via hidden file input), ".txt" download, yellow "Copy" pill.
6. **First-run gate**: full-page overlay on every load, same tokens: circle logo, title
   "Turn your volume down first.", the warning sentence, a Level slider (starts −20 dB and
   writes to state.levelDb), and a yellow "I understand, start" pill. Clicking it resumes
   the AudioContext and removes the overlay. Nothing plays before it.

## State (`js/store.js`)

```js
{
  version: 1,
  freq: 1000,              // Hz, 20..20000
  playing: false,
  levelDb: -18,            // -60..-6
  eqOn: true,
  preampDb: 0,             // applied preamp
  preampAuto: true,        // when true preampDb = -max(0, max enabled positive gain)
  bands: [],               // ≤ 8 of {id, type:'PK'|'LSC'|'HSC', fc, gain, q, enabled}
  selectedId: null,
  draft: { kind:'peak'|'dip', start:null, top:null, end:null },  // Hz or null
  theme: 'dark'|'light',   // default 'dark'
}
```
Store API: `store.get()`, `store.subscribe(fn)` (fn receives the whole state after every
change), and actions: `setFreq(hz)`, `setPlaying(bool)`, `setLevel(db)`, `toggleEq()`,
`setPreamp(db)` (sets preampAuto=false), `setPreampAuto()`, `setTheme(t)`,
`mark('start'|'top'|'end')` (records `state.freq` into the draft; when the draft has at
least `top`, or both `start` and `end`, the caller may `commitDraft()`), `commitDraft()`
(→ band via `dsp.bandFromMarks`, clears draft, selects the new band; refuses at 8),
`setDraftKind(kind)`, `undo()` (removes the last draft mark, or if the draft is empty the
most recently created band), `clearDraft()`, `updateBand(id, patch)`, `removeBand(id)`,
`selectBand(id)`, `load(state)` (replace, validating shape and clamping ranges).
Persisted fields: everything except `playing`. Auto-commit rule for rev 1: the draft
commits automatically once all three marks exist; a Top-only draft commits when the
user presses Enter or clicks the (always available) "Add band" text link in the panel.

## DSP (`js/dsp.js`) — pure functions, no DOM

- `FMIN=20, FMAX=20000, FS=48000`
- `freqToX(f, width)` / `xToFreq(x, width)` log mapping.
- `coeffs(band)` RBJ Audio EQ Cookbook, Q form, for `PK`, `LSC`, `HSC`:
  returns `{b0,b1,b2,a0,a1,a2}` (unnormalised).
- `magnitudeDb(band, f)` from the coefficients (evaluate H(e^{jw})).
- `responseDb(bands, f)` = sum over enabled bands (+ nothing for preamp; the graph shows
  bands only).
- `bandFromMarks(draft)` → `{type:'PK', fc, gain, q}`: fc = top if present else
  sqrt(start·end); q = fc / |end − start| when both edges exist, clamped 0.3…10, else 2.0;
  gain = −3 for peak, +3 for dip. Round fc to integer Hz, q to 0.05.
- `autoPreamp(bands)` = −max(0, max positive gain among enabled bands), one decimal.
- Format helpers: `fmtHz(f)` → "3 100" (thin-space U+2009 thousands, integer Hz),
  `fmtK(f)` → "2.5k" / "105" for tick labels.

Match the mock's curve exactly: the mock's Python in `design/build_mocks.py`
(`coeffs`, `band_db`) is the reference implementation; port it 1:1.

## Audio (`js/audio.js`)

```js
const engine = new AudioEngine();   // creates nothing until start()
await engine.start();               // creates AudioContext on the user gesture, builds graph
engine.setFrequency(hz);            // osc.frequency.setTargetAtTime(hz, now, 0.008)
engine.play(); engine.stop();       // toneGain ramps 0↔1 over 15 ms (linearRamp); no clicks
engine.setLevel(db);                // level gain = 10^(db/20), setTargetAtTime 0.01
engine.setBands(bands, eqOn, preampDb); // 8 fixed BiquadFilterNodes; unused/disabled → peaking gain 0; eqOn=false → all flat and preamp 1
engine.state                        // 'idle' | 'running'
engine.analyserDb()                 // returns current output RMS in dBFS (for QA), from an AnalyserNode at the end of the chain
```
Graph: `OscillatorNode(sine)` → `toneGain` → `preampGain` → `biquad[0..7]` → `levelGain`
→ `ceiling` (GainNode fixed 0.5, i.e. −6 dBFS) → `DynamicsCompressorNode` (threshold −3,
ratio 20, attack 0.001, release 0.05; a safety net only) → `AnalyserNode` → destination.
Biquad types map: PK → `peaking`, LSC → `lowshelf`, HSC → `highshelf`; Web Audio's
peaking Q is RBJ Q, so pass fc, Q, gain directly. Shelf Q: Web Audio ignores Q for
shelves; that is acceptable for rev 1 (the graph will use RBJ shelf-with-Q; note the
mismatch in a code comment). Never let output exceed the ceiling by design: preamp is
applied before the biquads. Frequency changes must glide, never jump.

## Sweep strip (`js/sweep.js`)

`new SweepStrip(svgEl, { onFreq(hz), onPointerDown() })`. Draws the tape from the mock
(`tape_svg`): minor ticks, major ticks with labels 20 50 100 200 500 1k 2k 5k 10k 20k,
a 1.5 px ink needle. Redraws on resize (ResizeObserver). Pointer: `pointerdown` on the
SVG sets frequency from x and calls `onPointerDown` (the app starts the tone and latches);
`pointermove` while captured updates frequency; `pointerup` keeps playing. `update(hz)`
moves the needle. Cursor: `ew-resize`.

## Graph (`js/graph.js`)

`new Graph(svgEl)`; `graph.render(state)` draws: hairline grid at the major
frequencies and at −12/−6/0/+6/+12 dB (0 dB line slightly stronger), axis labels as in
the mock, dashed ghost curve per enabled band, the summed curve (2.2 px accent, no fill),
draft marks as 3.5 px ink dots on the curve with labels "start 2.5k" / "top 3.1k" /
"end 3.75k" positioned as in the mock (start label left-anchored, end right-anchored,
top raised), a small number at each band's fc just above the bottom axis (accent for the
selected band, mute otherwise), and the playhead (1 px, `--playhead`). Range ±12 dB;
values beyond are clipped at the edge. Redraw on resize. Use `requestAnimationFrame`
coalescing so dragging the sweep doesn't redraw more than once per frame.

## Export (`js/export.js`)

- `toPeqText(state)`:
  ```
  Preamp: -2.0 dB
  Filter 1: ON PK Fc 105 Hz Gain 2.0 dB Q 0.70
  ```
  Bands sorted by fc, numbered from 1, only enabled bands as `ON` (disabled bands are
  omitted). Gain one decimal, Q two decimals, Fc integer. Exactly this spacing.
- `copyText(text)` via `navigator.clipboard.writeText`, resolving to true/false.
- `downloadText(filename, text)` and `downloadJson(filename, obj)` via Blob + anchor.
- `sessionToJson(state)` / `sessionFromJson(text)` (validate; throws on bad shape).
- Filenames: `dms-sweep-peq.txt`, `dms-sweep-session.json`.

## Storage (`js/storage.js`)

`save(state)` (debounced 300 ms, key `dms-sweep:v1`, all fields except `playing`),
`load()` → state or null. Both wrapped in try/catch; a failure is silent.

## Keyboard (global, in `app.js`, ignored while typing in an input)

- `←` / `→`: freq × 0.99 / × 1.01; with Shift × 0.95 / × 1.05. Clamped 20…20000.
- `Space`: play/stop toggle.
- `1` `2` `3`: mark start / top / end at the current frequency.
- `D`: toggle draft kind peak/dip. `Z`: undo. `Esc`: clear draft. `Enter`: commit a
  top-only draft.
- Global keydown handlers must not swallow browser shortcuts (Cmd/Ctrl combos).

## Acceptance (what "done" means)

1. `python3 -m http.server 8080` from the repo root, open `http://localhost:8080/`,
   no console errors or 404s.
2. Gate shows; nothing plays before "I understand, start"; after it `AudioContext.state`
   is `running`.
3. Click and drag on the tape: readout, needle, and graph playhead move together and
   match `dsp.xToFreq`. 20 Hz at the left edge, 20 kHz at the right, 1 kHz at 56.6 % (ln 50 ÷ ln 1000).
4. Press 1, 2, 3 at ~2.5k / 3.1k / 3.75k: a band appears with fc 3100, Q ≈ 2.5, gain −3,
   the graph shows the notch, and the band row is selected.
5. With EQ on, `engine.analyserDb()` at 3100 Hz is ≈ 3 dB lower than with EQ off.
6. Export text matches the format above line for line; Copy writes the same text.
7. Reload restores bands, freq, level, theme; the gate shows again.
8. Theme toggle switches tokens instantly and persists.
