# DMS Sweep

A browser tool for EQing headphones and IEMs by ear: play a sine tone, sweep it slowly,
mark the peaks and dips you hear, and turn the marks into an 8-band parametric EQ you can
paste into any PEQ app. Static site, no backend.

Local preview:

```
python3 -m http.server 8080
```

then open http://localhost:8080.
